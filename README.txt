ბიჭის დაბადების დღის მოსაწვევი — HTML + CSS + JavaScript

ფაილები:
- index.html — გვერდის სტრუქტურა
- style.css — ფერები, განლაგება და ანიმაციები
- script.js — ღილაკების მოქმედება და კონფეტი

როგორ ნახო:
1. ამოაარქივე ZIP ფაილი.
2. გახსენი საქაღალდე VS Code-ში.
3. გახსენი index.html ბრაუზერში (ან გამოიყენე Live Server).

როგორ ატვირთო Vercel-ზე:
1. ატვირთე სამივე ფაილი GitHub-ის ახალ repository-ში.
2. შედი https://vercel.com/ და აირჩიე Add New → Project.
3. დააკავშირე repository და დააჭირე Deploy-ს.
4. მიღებული საჯარო ლინკი გაუგზავნე სტუმრებს.

თარიღები: დაბადების დღე — 5 ნოემბერი; ზეიმი — 7 ნოემბერი.
ადგილი/დრო: მოსაწვევში წერია, რომ დეტალებს პირადად მისწერ.
პასუხები არ ინახება და არსად იგზავნება.
